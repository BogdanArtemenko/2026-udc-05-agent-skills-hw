# Architecture Deep Dive

## When to use this

Use this skill when the task requires understanding or explaining the architecture of the widget-registry library, including:

- how widgets are registered and created;
- responsibilities of `core`, `widgets`, and entry-point modules;
- where a new feature or architectural change belongs;
- why widgets follow the current folder and registration structure.

Always read `references/architecture.md` before answering.

Treat that document as the authoritative source of truth for the project's architecture. Do not infer architectural details that are not described there or in the project source code.
